> Учебный проект по программно-определяемому радио: от первых приёмников в **GNU Radio** до управления ADALM-PLUTO через **SoapySDR**, передачи IQ-отсчётов и сохранения принятого сигнала.

## Что умеет проект

| Часть                              | Что делает                                                                                  |
|:---------------------------------- |:------------------------------------------------------------------------------------------- |
| [`main.cpp`](dev/main.cpp)         | Единая программа: передаёт тестовый I/Q-сигнал или принимает поток, в зависимости от флага. |
| [`plot_pcm.py`](tools/plot_pcm.py) | Строит графики I и Q из записанных PCM-файлов.                                              |
| [`GNURadio/`](GNURadio/)           | Flowgraph-файлы ранних заданий: FM-приём и визуализация сигнала с ADALM-PLUTO.              |
| [`DevLog.md`](DevLog.md)           | Отчёты по семи лабораторным: схемы, ход работы, графики и материалы.                        |

Параметры эксперимента: пресеты **800 и 900 МГц**, **1 MSPS**, один канал и формат `CS16` (`I, Q, I, Q, ...`).

## Быстрый старт

### Что нужно установить

- CMake 3.16+ и компилятор с поддержкой C++;
- [SoapySDR](https://github.com/pothosware/SoapySDR);
- драйвер SoapySDR для PlutoSDR / libiio;
- ADALM-PLUTO, подключённый по USB;
- для графиков: Python 3, `numpy` и `matplotlib`.

Проверить, что устройство видно через SoapySDR, можно так:

```bash
SoapySDRUtil --find
```

В выводе ожидается устройство с драйвером `plutosdr`.

### Сборка

```bash
cmake -S dev -B build
cmake --build build
```

После сборки появится единая программа `build/sdr`.

### Запуск эксперимента

В двух терминалах запустите приёмник и передатчик:

```bash
# Терминал 1: приём на 800 МГц
./build/sdr Rx --freq 1

# Терминал 2: передача на той же частоте
./build/sdr Tx --freq 1
```

Поддерживаются также флаги `--rx` и `--tx`. `--freq 1` выбирает 800 МГц, `--freq 2` — 900 МГц. Режимы создают IQ-дампы `rxdata.pcm` и `txdata.pcm` в текущей директории. Их можно посмотреть так:

```bash
python3 tools/plot_pcm.py
```

> [!WARNING]
> Передача в радиоэфир регулируется законодательством. Для первых опытов лучше использовать эквивалент нагрузки, экранированное соединение или разрешённый диапазон. Частоту, мощность и усиление обязательно проверяйте перед запуском.

## Как устроен эксперимент

```mermaid
flowchart LR
    A[main.cpp: Tx\nтестовый IQ-буфер] --> B[SoapySDR]
    B --> C[ADALM-PLUTO\nTX · 800 MHz]
    C -. радиоэфир / кабель .-> D[ADALM-PLUTO\nRX · 800 MHz]
    D --> E[SoapySDR]
    E --> F[main.cpp: Rx\nrxdata.pcm]
    F --> G[plot_pcm.py\nграфики I/Q]
```

В передатчике создаётся треугольный тестовый сигнал, где I и Q имеют одинаковое значение. Для записи на передачу используются метки времени: пакет планируется немного «вперёд» относительно аппаратного времени SDR. Это помогает не отправить его слишком поздно.

## Лабораторные работы

Курс начинается с радиоприёмника в GNU Radio, затем переходит к управлению
PlutoSDR из кода, обработке буферов I/Q и передаче между двумя SDR. Отчёт по
каждому занятию, схемы обработки и доступные графики находятся в
[`DevLog.md`](DevLog.md).

| Занятие | Практическая работа |
| :-- | :-- |
| 1 · 8 сентября | Архитектура ADALM-PLUTO; GNU Radio; построение FM-приёмника. |
| 2 · 15 сентября | Приёмник и передатчик в GNU Radio. |
| 3 · 22 сентября | SoapySDR/libiio; инициализация устройства и получение I/Q-отсчётов. |
| 4 · 29 сентября | Продолжение работы с устройством и буферами I/Q. |
| 5 · 6 октября | Буферы и передача сэмплов между двумя SDR. |
| 6 · 13 октября | Приём-передача сэмплов; свёртка. |
| 7 · 20 октября | Продолжение обмена сэмплами между двумя SDR. |

В каталоге [`GNURadio/`](GNURadio/) сохранены flowgraph-файлы GNU Radio
Companion и Python-граф, который Companion сгенерировал из одного из них.
Flowgraph приёмника включает настройку частоты PlutoSDR, FIR-фильтр,
демодулятор WFM и отображение сигнала; отдельный TX-flowgraph среди
сохранённых файлов отсутствует.
